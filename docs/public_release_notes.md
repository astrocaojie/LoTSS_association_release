# Public Release Notes

This repository is prepared as a reusable open-source release of the LoTSS
radio-component association pipeline. Large survey data, generated catalogues,
figures, logs, checkpoints, and machine-specific paths are excluded.

Current release metadata:

- Package name: `lotss-association`
- Python import name: `lotss_association`
- License: MIT
- Recommended configuration: `configs/real_lotss_conservative.yaml`

Before archiving a journal release, add the final paper DOI and any data-access
links to `CITATION.cff` and `README.md`.
